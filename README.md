# 🏫 Smart School 360: AI-Driven Campus Management
An advanced, professional-grade School Management System integrated with Biometric Intelligence and Career Analytics.

## 🌟 Why this Project? (Developer's Vision)
As a passionate developer, I built **Smart School 360** to solve real-world educational challenges. This project isn't just about code; it's about optimizing resources using **OOPS**, ensuring data integrity with **Secure Database Design**, and enhancing user experience through **Computer Vision**.

## 🚀 Core Pillars of the Application
1. **Biometric Attendance (AI):** Uses OpenCV for real-time face detection with a custom-built **Cooldown Logic** to optimize database performance.
2. **Career Recommendation Engine:** A logic-driven module that analyzes academic scores to predict future professional paths.
3. **Secure Admin Dashboard:** A full **CRUD** (Create, Read, Update, Delete) interface with secure session management.

## 🛡️ Security & Optimization Features
- **SQL Injection Protection:** Used parameterized queries (`?` placeholders) to safeguard the SQLite database.
- **Resource Management:** Implemented a 10-second cooldown in the vision pipeline to prevent redundant DB writes.
- **Defensive Programming:** Comprehensive error handling (Try-Except blocks) to ensure zero runtime crashes.

## 🛠️ How to Run this Project?
1. **Clone the Repo:** `git clone https://github.com/pobbala-sivaramakrishna369/Smart-School-360.git`
2. **Install Requirements:** `pip install -r requirements.txt`
3. **Launch App:** `streamlit run SmartSchool360.py`
